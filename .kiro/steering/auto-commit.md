# Auto-Commit Steering

## Instructions

Commit changes when:
- A session completes successfully
- You've achieved a meaningful result

Do NOT commit blindly on every file save.

## Commit Message Format

When committing at session end, use: "Update: Changes made during session [description]"

## When to Skip Commits

- Testing/experimenting (WIP)
- Unrelated multiple changes
- When explicitly asked not to commit
